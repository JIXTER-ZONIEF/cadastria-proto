# Cadastria · prototype jouable (Metz)

Prototype web jetable d'un jeu de simulation immobilière géolocalisée, sur un vrai quartier de **Metz**.
Achète des cases, construis des aménités, regarde la valeur se propager au voisinage (le tien et celui des voisins), perçois ta rente.

- **Jouer** : ouvre `index.html` (ou la page publiée).
- **Données** : socle de valeur dérivé de la densité de POI © OpenStreetMap (contributors).
- **Valeurs de jeu** : ce ne sont **pas** les vrais prix immobiliers.

Prototype de validation du *fun* uniquement. Le moteur économique de production vit ailleurs (`cadastria-econ-core`).
